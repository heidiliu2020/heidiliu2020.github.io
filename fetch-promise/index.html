Content-Type

  • 決定 server 如何處理 Request
  • 根據不同的 Content-Type，需修改 body 如何解析接收到的資料格式

credential

對 mode 的誤解

  • mode: 'no-cors' 並不能突破 CORS 限制，而是會回傳一個空的 response
  • 這條指令只是跟瀏覽器說：「我沒有要拿 response，不用傳錯誤訊息給我」
  • 要在瀏覽器解決 CORS 限制，必須在 Server 端加上開 CORS 的 header
