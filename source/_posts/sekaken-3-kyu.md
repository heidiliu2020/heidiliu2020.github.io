## 世界遺產檢定

檢定介紹：[世界遺產檢定](https://www.sekaken.jp)是一項以 UNESCO 世界遺產為主題的檢定，內容涵蓋世界遺產制度、日本世界遺產、世界文化與自然遺產、歷史、宗教、建築、文明與地理等知識。
應考日期：2026/07/05 世界遺產檢定 3 級合格（70/100）

老實說分數不算高，但因為想在今年出發熊野古道前考到檢定，因此是在短時間準備，做了三回考古題後，確信只要把握基本題至少能及格就放心應考了，因此整段準備重點不在於滿分，而是抓住常見考題和重點，也是這次過程中的最大收穫。

### ch1. 世界遺產的基礎知識

+ ⭐️世界遺產需具備「**顕著な普遍的価値（OUV）**」
    + OUV = Outstanding Universal Value，核心精神在於保護全人類共同財產
    + フランス文化大臣がユネスコ会議で行った、｢世界文明の1ページを刻む芸術は、**分割できない我々の遺産**である｣
+ 世界遺産列表
+ ⭐️世界遺產分三類
    + 文化遺產
    + 自然遺產
    + 複合遺產
+ 世界遺產條約
    + **保護與保全遺產的義務和責任屬於遺產保有國**
    + 世界遺產基金
    + 誕生的契機：阿布辛貝神殿的遷移計劃，源於 1960 年埃及尼羅河的アスワン・ハイ・ダム（Aswan High Dam）阿斯旺地區水壩建設
    + 理念：最初的世界文明、世界藝術是不能分割的遺產

#### 世界遺產的推薦與登錄

+ 推薦需滿足五個必要條件：
    + 遺產所有國家是世界遺產條約的契約國
    + 記載於各國的**暫定清單**需接受**プレリミナリ・アセスメント（事前評價）**，評價後才能進行推薦
    + 遺產由「保有國」自己提出申請推薦
    + 遺產屬於不動產
    + 遺產受到「保有國」法律保護
+ 登錄世界遺產
    + 向ユネスコ（UNESCO）的世界遺產中心推薦的世界遺產，可依照類別分為：
        + ⭐️自然遺產：透過 **IUCN（國際自然保護連合）**
        + ⭐️文化遺產：透過 **ICOMOS（國際紀念物遺跡會議）**
+ 從提出推薦到登錄期間約一年半左右，但如果遺產需要緊急保護，則可透過「緊急的登錄推薦」管道進行
+ 日本：依照類別選定，最終由**世界遺產條約關係省廳聯絡會議**選出要推薦的遺產：
    + 自然遺產：文化廳或內閣官房
    + 文化遺產：從環境省與林野廳的暫定清單選出候補
+ 世界遺産委員会では「登録」、「情報照会」、「登録延期」、「不登録」の4段階の決議を行います

> ⭐️世界遺產登錄流程：
> 1. 暫定清單（Tentative List）
> 2. 事前評價（プレリミナリ・アセスメント）
> 3. 推薦書提交
> 4. IUCN / ICOMOS 評估
> 5. 世界遺產委員會決定

#### 世界遺產的概念

+ 需滿足十項登錄基準中一項以上
    + (i)~(vi) 文化遺產：(ii) 文化交流/(iv) 建築景觀
    + (vii)~(x) 自然遺產：(ix) 生態系多樣性
+ ⭐️緩衝地帶（Buffer zones）
+ ⭐️真正性（Authenticity）：具備獨特性、繼承傳統與技術
+ ⭐️完全性（Integrity）：具備充分的法律、預算與保護計劃
+ 文化的景觀
    + シリアル・サイト（Serial Site）：系列遺產
    + トランスバウンダリー・サイト（Transboundary Site）：跨國界遺產

#### ⭐️ユネスコ UNESCO

+  國際聯合教育科學文化機關（UNESCO：ユネスコ）：是世界遺產制度制定者，不直接管理遺產
+  平和のとりで（和平的堡壘）

#### 世界遺產與日本

+ 1992 年
    + 在 UNESCO 制定世界遺產條約二十年後 ，日本成為第 125 個會員國
    + 於巴西里約初次舉辦國連的「地球高峰會」
+ 1993 年：法隆寺地區的佛教建築群、姬路城、屋久島、白神山地四項初登錄世界遺產
+ 2025 年 3 月：世界遺產登錄 26 件

#### 世界遺產觀光

+ オーバーツーリズム（Overtourism）：觀光公害

#### 無形世界遺產・世界的記憶

+ 2003 年提出「**無形文化遺產條約**」
+ 將書籍、文件資料與繪畫等紀錄作為「世界的記憶」進行保護
