for…in vs for…of

  • for…in
    • 是 ES5 標準
    • 遍歷的是鍵（key）
    • 通常用來遍歷 object
    • 會遍歷繼承的屬性，可使用 hasOwnProperty() 檢查是否為非繼承的屬性
  • for…of
    • 是 ES6 標準，可解決 for…in 產生的問題
    • 遍歷的是值（value）
    • 不能遍歷 object
    • 可搭配 break、continue、return 語法使用
